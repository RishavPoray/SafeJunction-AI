\# Security Policy



\## Supported Version



The current version of SafeJunction AI is the actively maintained version.



\## Reporting a Security Issue



If you discover a security vulnerability in SafeJunction AI, please report it privately to the project maintainer rather than publicly disclosing it.



Please include:



\- A description of the issue

\- Steps to reproduce it

\- Potential impact

\- Any relevant screenshots or logs



\## Responsible Use



SafeJunction AI is a prototype for traffic safety analysis. It should not be used as the sole decision-making system for real-world emergency response or traffic control.



Users should avoid uploading videos containing unnecessary personal or sensitive information.
